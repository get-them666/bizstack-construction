# BuildStack Construction — Free Marketing System

## 📁 What's in This Folder

1. **email_templates.py** — Ready-to-use email templates
   - Monthly newsletter
   - Permit alerts
   - Review requests
   - Follow-ups
   - Seasonal promotions

2. **social_media_calendar.py** — 30 days of post content
   - Mix of before/after, educational, testimonials
   - Optimized for Facebook, Instagram, Nextdoor, TikTok
   - Includes hashtags

3. **partnership_outreach.py** — Email templates for partnerships
   - Realtors
   - Property managers
   - Insurance adjusters
   - Architects

4. **review_automation.py** — Code to auto-request reviews
   - SMS and email templates
   - Integration ready

5. **blog_post_template.md** — SEO blog post structure
   - Keyword optimization
   - Local focus (Hampton Roads)

6. **setup_checklist.md** — Step-by-step setup guide
   - Google Business Profile
   - Directory submissions
   - Social media accounts
   - Daily/weekly/monthly tasks

## 🚀 Quick Start

### Today (2 hours):
1. Open `setup_checklist.md`
2. Complete Google Business Profile
3. Submit to 3 directories (Yelp, Angi, HomeAdvisor)
4. Create Facebook page
5. Post Day 1 content from social media calendar

### This Week (5 hours total):
1. Complete all directory submissions
2. Create Instagram + Nextdoor accounts
3. Post 3x on social media
4. Send 5 partnership emails
5. Request reviews from last 3 customers

### This Month (ongoing):
1. Post 3-4x per week on social media
2. Send 1 newsletter email
3. Write 1 blog post
4. Meet 1 realtor/property manager
5. Request 5+ reviews

## 💡 Pro Tips

1. **Consistency > Perfection** — Post regularly, even if it's not perfect
2. **Engage, Don't Broadcast** — Comment on others' posts, answer questions
3. **Photos Win** — Before/after photos get 3x more engagement
4. **Reviews = Revenue** — Each Google review = ~$500 in future revenue
5. **Track Everything** — Ask every lead "How did you hear about us?"

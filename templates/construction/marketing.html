To turn posting on, the Page needs a token (about three minutes, once):

  1. Go to developers.facebook.com/apps and create an app of type Business.
  2. Open Tools → Graph API Explorer, select that app, and add the permissions pages_show_list, pages_read_engagement, pages_manage_posts.
  3. Generate a User token, then call /me/accounts — copy the Page's id and its access_token.
  4. Paste both into /opt/bizstack/construction.env on the server as FB_PAGE_ID and FB_PAGE_TOKEN, then docker compose restart construction.

The Page token from step 3 is long-lived when generated from a Business app. If it ever expires, the error appears here verbatim.

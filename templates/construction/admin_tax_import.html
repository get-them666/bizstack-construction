How it works

  1. Upload a CSV exported from PNC PINACLE (business checking or credit card).
  2. Each row is hashed (SHA-256(date | amount | description)) so re-importing the same file is safe — duplicates are skipped automatically.
  3. Internal transfers (TRANSFER, ZELLE TO, ACH TO) and website payouts already in the payments table are detected and skipped.
  4. Remaining rows are tagged by keyword: Home Depot/Lowe's/Sherwin → BuildStack Construction; TurnOver/Hospitable/Broom → Broom Service.
  5. Override any tag in the preview before committing.
